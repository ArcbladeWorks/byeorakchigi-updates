# 벼락치기 – 1점이라도!

ARCBLADE WORKS의 Windows·Android 학습 프로그램 배포 채널입니다.

설치 파일은 Releases에서 받습니다. v0.6.2·v0.6.3 사용자는 연결판을 한 번 덮어 설치한 뒤 앱 상단의 업데이트 버튼으로 프로그램과 문제팩을 함께 확인할 수 있습니다. Android는 설치 화면에서 업데이트를 확인해야 합니다.

업데이트 버튼을 누르면 서명과 파일 해시를 확인하고 문제팩을 적용합니다. 새로운 문항은 새 학습 세트부터 사용하며 진행 중인 풀이와 기록은 보존합니다.

공개 자료에는 검수 완료·과목별 120문항 이상인 자료만 포함합니다. 기존 가족용 기기에 저장된 초안과 기록은 별도로 보존합니다. 실제 학교 기말고사 범위는 학교 안내를 확인해 주세요.

앱 소스코드와 개인 학습 기록은 이 저장소에 게시하지 않습니다. 무료 배포는 소스코드 공개 또는 제3자 저작물에 대한 사용권 부여를 뜻하지 않습니다.
